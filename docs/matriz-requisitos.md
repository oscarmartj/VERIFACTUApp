# Matriz de requisitos con evidencias

Consulta normativa: 2026-11-09 (ver `docs/normativa/fuentes.md`). Estado del código: versión 0.1.0.

**Leyenda de estados:** IMPL+PRUEBA = implementado y con prueba automática superada (en el **simulador local**, salvo que se indique); IMPL = implementado sin prueba automática específica; PEND-AEAT = implementado, falta la prueba real contra el entorno de pruebas de la AEAT; PEND = pendiente; BLOQ = caso no soportado y bloqueado; N/A = no aplica a este sistema.

> Un XML que valida localmente o un QR que se puede escanear no acreditan por sí solos el cumplimiento: ninguna prueba se ha ejecutado todavía contra los servicios de la AEAT.
